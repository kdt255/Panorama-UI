# Panorama UI — by kdt255

[![Preview Video](https://img.youtube.com/vi/LqJRINHNuYQ/maxresdefault.jpg)](https://youtu.be/LqJRINHNuYQ)

> 🎥 **Preview Video:** https://youtu.be/LqJRINHNuYQ

Counter Strike Panorama UI built with **Dear ImGui**, **DirectX 11**, and **FreeType**.

### Info
- **Renderer**: DirectX 11 (x64)
- **Backdrop**: Real-time HLSL multi-pass Gaussian Blur
- **Components**: 1:1 Panorama widgets (Combos, Sliders, Slider Checkboxes, Checkboxes, RGBA Color Pickers, Buttons, Scrollbar & Live Menu Scaling)

### Build
1. Open **`example_panorama_ui.sln`** in Visual Studio.
2. Select **`Debug | x64`** or **`Release | x64`** and build (`Ctrl+Shift+B`), or run **`build_win32.bat`** from the x64 Native Tools Command Prompt.
